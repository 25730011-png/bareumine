# 바름이네

> 휴대폰 하다 지치면, 바름이네 놀러 와

휴대폰을 쓰다가 고개를 오래 숙이거나 화면에 얼굴을 너무 가까이 대면, 거북이 **바름이**가 자기 집으로 초대해 줘요.
집에 놀러 가서 3분 동안 목을 풀고 오는 자세 습관 웹앱이에요. 융합 콘텐츠 활용 수업의 생성형 AI 서비스 BM 과제로 만들었어요.

## 화면

| 화면 | 내용 |
|---|---|
| 로그인 표지 | 바름이네 집, 들어가기 / 가입 / 둘러보기 |
| 첫 만남 (4단계) | 바름이 인사 → 캐릭터 고르기(숙이·숙돌이) → 집 소개 → 센서 권한 |
| 바름이네 (홈) | 방 4개(거실·창가·마당·침실), 오늘의 습관 4가지 실시간 집계, 바름이 초대 카드 |
| 초대장 | 기준을 넘으면 자동으로 뜸 (진동 + 바름이 목소리) |
| 거실 · 목 쉼 | 턱 당기기 → 옆목 늘리기(좌우) → 가슴 펴기, 각 1분, 음성 안내, 배경 소리 |
| 창가 · 눈 쉼 | 먼 곳 보기 → 눈 감기 → 눈 굴리기 (플러스) |
| 쉼 완료 | 칭찬, 오늘 몇 번째 쉼인지 |
| 쉼 기록 | 시간대별 고개 숙임 그래프, 지금 자세, 최근 쉼 |
| 바름이 일기 | 주간 방문 횟수, 방별 방문, 한 줄 요약 |
| 내 정보 / 요금제 | 캐릭터 변경, 감지 설정, 시연 모드 / 무료·플러스·오피스 |

## 습관은 어떻게 알아?

- **고개 숙임**: 휴대폰 기울기 센서(`DeviceOrientation`)로 휴대폰이 바닥과 이루는 각도를 봐요. 손에 들고 있는데 35° 아래면 고개를 많이 숙인 것, 60° 아래면 살짝 숙인 것으로 세요. 책상에 내려놓은 상태는 세지 않아요.
- **화면 가까이**: 내 정보에서 켜면 앞 카메라와 MediaPipe 얼굴 감지로 얼굴이 화면 너비의 55%를 넘는지만 확인해요. 영상은 저장하거나 보내지 않아요.
- **오래 사용 / 자정 이후 사용**: 앱이 켜져 있는 시간으로 세요.
- 모든 기록은 내 휴대폰(`localStorage`)에만 저장돼요. 서버가 없어요.

> 지금은 웹 시연판(MVP)이라 앱을 켜 둔 동안에만 감지할 수 있어요. 실제 서비스는 안드로이드 앱으로 만들어 백그라운드에서 감지하고, 알림으로 바름이 초대장을 보내는 걸 목표로 해요.

## 시연하는 법

1. 휴대폰으로 열면 실제 센서로 동작해요. iPhone은 첫 화면에서 "센서 권한 허용할게"를 눌러야 해요.
2. 컴퓨터로 열거나 빨리 보여 줄 때는 **내 정보 → 시연 모드**를 써요.
   - `샘플 기록 채우기`: 일주일치 기록이 채워져서 일기·기록 화면이 바로 보여요.
   - `목 쉼 초대 받기` / `눈 쉼 초대 받기`: 초대장을 바로 띄워요.
   - `가짜 기울기 쓰기`: 슬라이더로 각도를 바꿔 볼 수 있어요.
   - 목 쉼 초대 기준을 `1분 (시연)`으로 두면 실제로 1분만 숙여도 초대장이 와요.
3. 요금제에서 "플러스로 놀러 갈게"를 누르면 결제 없이 바로 플러스가 돼요. 창가·마당·침실, 숲·파도 소리, 지난 주 일기가 열려요.

## 로그인 (회원가입 · 로그인 · 로그아웃)

- `js/firebase-config.js`가 비어 있으면 **시연용 계정**으로 동작해요. 이 기기(브라우저) 안에서만 가입·로그인이 되고, 비밀번호는 해시로 저장돼요.
- 진짜 로그인을 쓰려면 (무료):
  1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트 만들기
  2. Authentication → 시작하기 → 로그인 방법에서 **이메일/비밀번호** 사용 설정
  3. Authentication → 설정 → 승인된 도메인에 `아이디.github.io` 추가
  4. 프로젝트 설정 → 내 앱 → 웹 앱 추가 → 나오는 `firebaseConfig` 값을 `js/firebase-config.js`에 붙여 넣기
- 로그인한 사람마다 쉼 기록이 따로 저장돼요. 로그아웃은 내 정보 → 계정 칸에 있어요.

## GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만들어요. 예: `bareumine`
2. 이 폴더 안의 파일을 전부 올려요. `index.html`이 저장소 맨 위에 있어야 해요.
3. **Settings → Pages → Branch: `main` / `(root)` → Save**
4. 1~2분 뒤 `https://아이디.github.io/bareumine/` 주소로 열려요.
5. 휴대폰에서 열고 "홈 화면에 추가"를 하면 앱처럼 쓸 수 있어요.

> 센서, 카메라, 앱 설치는 **https**에서만 돼요. GitHub Pages는 https라서 그대로 쓰면 돼요.

## 아직 안 만든 이미지

아래 이미지는 아직 없어서 앱에 "이미지 준비 중" 빈 칸으로 나와요. 만들면 `pages/assets/img/`에 이 이름의 `.webp`로 넣고, `js/app.js`의 `MISSING` 목록에서 그 줄을 지우면 돼요.
동작 영상이 생기면 `pages/assets/video/`에 넣고 `js/app.js`의 `VIDEOS`에 `sukdol_neck: 'pages/assets/video/sukdol_neck.mp4'`처럼 적으면 쉼 화면에서 이미지 대신 영상이 재생돼요.

| 파일 이름 | 내용 |
|---|---|
| sukdol_phone / sooki_phone | 휴대폰 보며 고개 숙인 모습 |
| sukdol_chin / sooki_chin | 턱 당기기 |
| sukdol_neck / sooki_neck | 옆목 늘리기 |
| sukdol_chest / sooki_chest | 가슴 펴기 |
| sukdol_stretch / sooki_stretch | 기지개 켜기 (마당 1단계, 쉼 완료) |
| sukdol_twist / sooki_twist | 허리 좌우 돌리기 (마당) |
| sukdol_march / sooki_march | 제자리 걷기 (마당) |

## 쉼 화면 구성

방을 누르면 집 사진이 그 방 쪽으로 확대되면서 쉼 화면으로 들어가요. 쉼 화면은 **방 배경**(`room_living_bg` 등) 위에 **투명 배경 캐릭터 동작 사진**이 서 있는 구조예요. 캐릭터 동작 사진은 배경이 투명한 PNG로 만들어서 webp로 바꿔 넣으면 돼요.

## 폴더 구조

```
index.html          모든 화면
readme.md           이 설명
css/style.css       디자인
js/                 기능 코드
  app.js            화면 흐름
  store.js          기록 저장 (사람마다 따로)
  auth.js           로그인 · 가입 · 로그아웃
  firebase-config.js  Firebase 설정 (비우면 시연용 계정)
  sensors.js        기울기 · 얼굴 거리 · 사용 시간 감지
  sound.js          배경 소리 · 바름이 목소리
  vendor/           Firebase 라이브러리
data/manifest.json  홈 화면에 추가할 때 쓰는 앱 정보
pages/
  assets/img/       앱에서 쓰는 이미지 (가볍게 줄인 webp)
  assets/icons/     앱 아이콘
  image/            원본 캐릭터 · 배경 이미지
```
